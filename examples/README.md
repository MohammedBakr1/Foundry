# Examples

This folder is for additional examples — uses of the Foundry methodology that don't yet rise to the level of a fully documented case study, or simplified illustrative examples (for instance, a very small project showing how to fill in the `foundry/` template files in practice).

No content here yet.

Difference from `case-studies/`:

- `case-studies/` — real projects where the methodology was fully applied, backed by actual evidence.
- `examples/` — shorter teaching or illustrative examples, possibly partial or hypothetical, meant to show how to use Foundry itself.
